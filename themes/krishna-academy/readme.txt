== Description ==
Krishna Academy — блок-тема WordPress с поддержкой FSE (Full Site Editing), шаблонных частей и паттернов. Тема предназначена для академического сайта, включает пресеты типографики и цвета, а также интеграцию с Polylang (через отдельный плагин).
